# Приложение для анализа логов Nginx на yii2

Веб-приложение на базе Yii2 для парсинга, анализа и визуализации логов веб-сервера Nginx.

## Возможности (согласно ТЗ)

- **Парсинг логов** - автоматическое распознавание:
  - IP адреса
  - Даты / времени запроса
  - URL-адреса
  - User-Agent
  - Операционной системы
  - Архитектуры процессора (x86 / x64)
  - Браузера

- **Хранение данных** - сохранение всех данных в MySQL

- **Анализ и визуализация (Chart js)**:
  - График количества запросов по дням
  - Круговая диаграмма распределения браузеров (топ 3)
  - Таблица статистики по дням с информацией о популярных URL и браузерах

- **Фильтрация данных**:
  - По диапазону дат (от / до)
  - По операционной системе
  - По архитектуре процессора

- **Сортировка**:
  - По датам (возрастание / убывание)
  - По количеству запросов (возрастание / убывание)

## Установка и запуск

### 1. Скачивание и запуск Docker контейнеров, установка зависимостей

```bash
git clone reponame.git
cd repo
docker-compose up -d
docker exec yii_php composer install
```

### 2. Создание таблиц БД (миграции)

```bash
docker exec yii_php ./yii migrate
```

### 3. Загрузка логов в БД
Разархивируйте файл:
```bash
modimio.access.log.zip
```
в ту-же папку, где он находится и выполните консольную команду для загрузки логов:

```bash
docker exec yii_php ./yii logs/load /var/www/modimio.access.log
```

## Использование

### Веб-интерфейс

Откройте браузер и перейдите на:

```
http://localhost
```

Содержимое базы Вы можете посмотреть с помощью PHPMyAdmin на:

```
http://localhost:8080
```
### Фильтрация

На главной странице доступны фильтры:

1. **От** - начальная дата диапазона
2. **До** - конечная дата диапазона
3. **Ось** - выбор конкретной ОС
4. **Архитектура** - выбор архитектуры (x86 или x64)

После выбора фильтров нажмите кнопку "Применить фильтры"

### Сортировка таблицы

- **Дата ↑** / **Дата ↓** - сортировка по дате
- **Кол-во ↓** / **Кол-во ↑** - сортировка по количеству запросов

### Графики

Приложение отображает два графика:

1. **Количество запросов по дням** - линейный график, показывающий динамику запросов
2. **Распределение браузеров (топ 3)** - круговая диаграмма процентного распределения браузеров
